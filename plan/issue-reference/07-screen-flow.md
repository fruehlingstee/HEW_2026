# 画面遷移図

> **2026-10-20変更:** ケーキの作成・編集と注文手続き（受取日選択・注文確認・決済）はPC専用とする。注文受付後の購入者向け画面（受付完了・注文内容／受取番号／状態の照会・キャンセル申請・返金状況確認）はPC・スマホに対応する。注文確定後のデザイン編集は不可。店舗管理・共有デザイン画面は引き続きPC専用で、共有URL表示・コピー・PC画像保存を維持する。3D編集のスマホ対応・タッチ配置操作は対象外とし、10月30日の3D判定と性能目標はPCで維持する。注文受付後の画面はスマホ向けUI・タップ操作とiPhone Safari／Android Chromeでの確認を実装・検証対象に含める。2026-10-13の全面PC専用方針はこの範囲で改訂し、それ以前のモバイル対応記述は履歴として扱う。

ルート名は実装時の基準案。既存ルーティングと衝突する場合は Issue 内で変更理由を記録する。

## 対応端末

| 対象 | PC | スマホ |
|---|---|---|
| ケーキ作成・編集、受取日選択、注文確認・決済 | 対応 | 対象外 |
| 受付完了、注文内容・受取番号・状態の照会 | 対応 | 対応 |
| キャンセル申請・申請結果・返金状況確認 | 対応 | 対応 |
| 店舗管理・製造指示書、共有デザイン・画像保存、デモ作成 | 対応 | 対象外 |

スマホでは受付メールの秘密トークン付き注文URLから照会する。デザイン編集用の権限やブラウザ内の保存データは必要としない。共有URLと注文照会URLは別の権限であり、共有画面に注文の個人情報を表示しない。受付の確定は従来どおりWebhook成功で判定し、未確定なら確認中表示とする。

キャンセル可否・返金条件・トークン検証はPCとスマホで共通とし、端末によって条件を変えない。再注文のための複製・編集と注文手続きはPCで行う。

## 購入者フロー

```mermaid
flowchart TD
    A["/stores/[slug]<br>商品説明"] --> B["/design/[id]/colors<br>スポンジ・クリーム色"]
    B --> C["/design/[id]/decorate<br>3D配置"]
    C --> D["/design/[id]/message<br>プレート"]
    D --> E["/design/[id]/pickup<br>受取日"]
    E --> F["/checkout/[designId]<br>注文・アレルゲン確認"]
    F --> G["/checkout/[orderId]/payment<br>15分hold・Stripe"]
    G -->|Webhook成功| H["/orders/[token]/complete<br>受付完了（PC・スマホ）"]
    G -->|期限切れ| X["枠解放・再選択"]
    H --> I["/orders/[token]<br>照会・キャンセル（PC・スマホ）"]
    C --> S["/share/[token]<br>共有URL・PC画像保存"]
```

購入画面の戻る操作ではデザイン ID を維持する。注文確定後は元デザインを編集せず、再注文は複製から始める。

## 店舗フロー

```mermaid
flowchart TD
    L["/store/login"] --> D["/store/dashboard"]
    D --> O["/store/orders<br>注文一覧"]
    O --> OD["/store/orders/[id]<br>詳細"]
    OD --> ST["状態更新"]
    OD --> P["/store/orders/[id]/print<br>製造指示書"]
    D --> C["/store/capacity<br>曜日・日別枠"]
    D --> M["/store/parts<br>パーツ管理"]
    ST --> O
```

店舗画面はログイン必須。全クエリをログイン店舗の `store_id` で制限し、別店舗 ID の URL を指定しても閲覧できないようにする。

## デモフロー

```mermaid
flowchart LR
    A["/demo"] --> B[サンプルデザイン]
    B --> C[3D操作]
    C --> D[疑似注文確認]
    D --> E[疑似完了]
    E --> F[デモ状態リセット]
```

デモでは顧客名・メールを収集せず、Stripe・本番容量・本番注文番号を利用しない。

## 代替・エラー経路

| 状況 | 表示・遷移 |
|---|---|
| WebGL / GLB 読込失敗 | SVG 上面図へ切替。再読込ボタンを表示 |
| 保存競合 | 最新デザインを再取得し、再操作を案内 |
| 受取枠売切れ | 選択画面へ戻し、最新空き日を再表示 |
| hold 期限切れ | pending を expired にし、受取日再選択 |
| 決済画面離脱 | hold 期限までは復帰可能。期限後は再取得 |
| Webhook 処理待ち | 「確認中」を表示し、完了ページで安全に再照会 |
| 不正/期限切れトークン | 存在を推測できない共通エラー |
| メール送信失敗 | 完了画面は維持。店舗側で再送可能 |
| オフライン展示 | 静止画・事前録画・説明用サンプルへ切替 |

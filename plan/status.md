### 技術スタック

| 領域 | 確定内容 |
|---|---|
| 言語 | **TypeScript**(全員共通。フロント・バックエンドとも) |
| フレームワーク | **Next.js(App Router)** フルスタック |
| ホスティング | **Vercel** |
| DB | **Neon(PostgreSQL)+ Prisma** |
| 3D | React Three Fiber + drei / Blender → glTF(Draco圧縮) |
| 状態管理 | Zustand |
| 決済 | Stripe(テストモード)+ Webhook |
| メール | Resend |
| 指示書PDF | 印刷CSS(`@media print`)。ライブラリ不使用 |
| 俯瞰配置図 | SVG 自前描画 |
| 外部ストレージ | **使用しない**(保存する画像がゼロのため) |

### 機能スコープ

**提供する:**
- ベース選択(サイズ・スポンジ・クリーム・外周デコ)+ 価格即時計算
- 3D飾り付けエディタ(ドラッグ配置、個数課金、サイズ別配置上限)
- メッセージプレート(**書体選択+文字入力のみ**)
- アレルゲン自動表示(特定原材料8品目 / 準ずる20品目、`contains` と `may_contain` を型分離)
- **店頭受取のみ**(受取番号で照合)
- 事前決済・即時キャプチャ / ステータス×日時の2軸による自動返金
- ゲスト注文 + ワンタイムトークン付きURLでの照会・キャンセル
- 店舗:パーツCMS / 予約枠(製造ポイント制)/ 注文管理 / 製造指示書自動生成

**提供しない(廃止決定済み):**
- ❌ 画像プリント(食用プリント)
- ❌ 配送(および配送料計算)
- ❌ 買い手の会員登録(認証ライブラリを導入しない)
- ❌ 手書きメッセージプレート(Canvas入力)

### 設計上の決定

- 配置座標は **JSON列ではなく `placements` テーブルに正規化**
- 製造指示書の配置図は **B案(2D SVG・番号付き)を主図**、3Dスクショを参考併載
- 製造指示書は **A4縦1枚**
- 消費税は **軽減税率8%の単一税率**(店頭受取のみのため)
- 予約枠は **製造ポイント制 + リードタイム**(個数上限ではない)
- 同時注文の競合は **`SELECT ... FOR UPDATE` の行ロック**で対処
- 店舗ログインは **自前の簡易セッション認証**(bcrypt + 署名付きHttpOnly Cookie)
- マルチテナントは **DB設計のみ**(`store_id`)。画面・デモは1店舗固定

| ② | バックエンド兼 店舗側フロント | 予約枠、製造指示書、店舗管理画面、店舗ログイン | Prisma Client / **印刷CSS** / date-fns / bcrypt |

# 3Dモデルの動作確認

```powershell
npm run dev -- --hostname 127.0.0.1 --webpack
```

`http://127.0.0.1:3000` でチョコケーキと絞りクリームのプレビューを開く。
ドラッグで回転、スクロールで拡大縮小できる。チェックボックスでクリームの表示を切り替え、「視点を戻す」で初期視点へ戻す。

## 使用モデル

- `models/bases/cake-base-chocolate.glb`
- `models/cream/cream_dec_1.glb`

配信用にこの2ファイルを `public/models/` 以下の同じ階層へコピーしている。
元モデルを更新した際は配信用ファイルも更新する。
クリームのDraco圧縮の解凍には `public/draco/` のローカルデコーダーを使う。
デコーダーは `three/examples/jsm/libs/draco/gltf/` からコピーしたもの。

モデルの形状・サイズ比を保持し、それぞれの底面中心を基準にケーキの上面へクリームを1個配置する。
元モデルには色指定がないため、表示側でチョコ色とクリーム色を設定している。
配置編集・保存・注文や料金計算との連携は、このプレビューには含まれない。

2026-10-29のローカル確認ではTurbopackのPostCSS処理が異常終了したため、上記の `--webpack` オプションで起動した。
